# Registro de conflicto y exportación DEIC53

El analista abre el caso con número DEIC53, fecha de ingreso, investigador activo y al menos el nombre de un adolescente. No adjunta archivos. Los demás datos del requerimiento pueden completarse después.

El investigador abre el caso asignado desde Mis registros, conserva los datos del analista y guarda avances. Para entregar requiere número MP, estado de investigación, ubicación, nombre y nacimiento o edad de cada adolescente, y un PDF. Las víctimas o denunciantes se registran cuando se conocen. El expediente llega a revisión del analista, que aprueba o rechaza. Un rechazo permite corregir el mismo caso y conserva los documentos anteriores.

Se mantienen los estados Informado y Concluido. El visto bueno es un dato de referencia del documento físico. La aplicación no administra turnos, firmas del jefe ni un estado de archivado.

La exportación del analista usa la hoja DEIC53 de DEIC53-2026.xlsx: 73 columnas de negocio más Columna1, conservada como dato adicional opcional. Incluye dos adolescentes por fila, respetando la inversión de sexo y alias del segundo bloque. Más adolescentes generan filas adicionales; folios, entrevistas y plazos solo aparecen en la primera para evitar sumar cantidades repetidas. Las víctimas y denunciantes se agrupan en las columnas correspondientes.

El tiempo de respuesta va desde la asignación hasta el primer informe. El plazo de entrega a análisis va desde el primer informe hasta la entrega a análisis. Fechas faltantes o diferencias negativas dejan el plazo vacío. La edad se calcula a la fecha de ingreso cuando hay nacimiento, o usa la edad reportada.

El archivo de referencia solo se leyó para identificar estructura y catálogos. No se importaron personas ni registros, no se modificó el Excel original y no se ejecutaron migraciones o cambios de índices.
